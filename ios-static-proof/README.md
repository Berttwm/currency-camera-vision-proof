## Lossless document transport repair

The first document run compiled, retained the original Mac baseline and completed its document call, but stopped before emitting the diagnostic because the combined uncompressed JSON exceeded4MB. That failure is preserved; it supplied no validated document/Simulator result. This repair changes transport only: each platform retains its baseline under the original4MB bound and caps decoded document JSON below16MB. The runner compresses the complete document JSON with Python's standard-library gzip, emits a SHA256/decoded-length envelope with base64 chunks of4096characters, and requires baseline plus encoded envelope below the original combined4MB wire bound. The private decoder enforces the decoded limit, length, SHA256 and UTF8 before parsing and running the unchanged v5c geometry/control checks. No records/options/pixels/thresholds are dropped or changed; the shared180second iOS deadline remains.
